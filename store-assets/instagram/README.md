## Exporting the PNGs (one-click per carousel)

The fastest way to get all 22 hero carousel PNGs at posting quality:

1. **Open the Figma file** (link above).
2. Select the **first slide** of Post 8.
3. In the right sidebar → **Export** panel:
   - Format: **PNG**
   - Multiplier: **2x** (that's 2160×2700 — IG will downscale)
   - Suffix: `@2x` (optional)
4. **Shift+click** each subsequent slide of the carousel to add it to the selection, OR shift+click on the parent page in the layers panel to select all of Post 8's frames.
5. Click **Export X layers**. Figma zips them.

Repeat for Posts 5, 3, 1.

**Faster shortcut for all 22:**

1. In layers panel, select the **Social Media page**
2. `File → Export frames` (or `Cmd+Shift+E`)
3. Figma exports everything on the page, correctly named per frame (`Post 8 · 1 Hook.png`, etc.)

**File naming tip:** I named every frame so the export filenames sort in post order. When you upload to IG, upload them in the order they appear in Finder.

## Uploading to Instagram (order matters)

IG carousel upload is order-sensitive — it posts in the order you select.

**Correct upload order for each carousel:**

- **Post 8:** 1 Hook → 2 Vent → 3 Reflection → 4 Point
- **Post 5:** 1 Hook → 2 (I'm sorry) → 3 (specific) → 4 (impact) → 5 (affirm) → 6 (concrete change) → 7 (no timeline) → 8 Closer
- **Post 3:** 1 Hook → 2 (I'm fine) → 3 (never listen) → 4 (Fine) → 5 (whatever) → 6 Closer
- **Post 1:** 1 Hook → 2 Raw draft → 3 Rewrite → 4 Closer

**Safety net:** before hitting "Post," scroll through the carousel preview in the IG compose screen. If anything's out of order, reorder there before publishing.

## Postcard workflow (Post 4, Week 3 onwards)

The postcard front slides in Figma have a grey placeholder rectangle where the Ideogram-generated art goes. Workflow per postcard:

1. **Generate the art** using one of the 6 prompts in [the original strategy doc](../../TODO.md) or the handoff from the previous session. Use Ideogram 2.0 Turbo, 4:5 aspect, "Illustration" style.
2. **Pick the best of 4** and upscale to 1600×1920 or higher.
3. **In Figma:** select the grey placeholder rectangle on the postcard front, drag-drop your image onto it. Figma replaces the fill with the image.
4. **Check the caption text still reads well** over the art. If the bottom third of the Ideogram output is busy, consider a scrim — add a rectangle with 40% white fill between the image and the text.
5. **Export front + back together** as a 2-slide carousel.

Posting cadence: one postcard per week, Monday slot, starting Week 3.

## Stories — how to use the 4 templates

Stories are vertical (9:16, 1080×1920). The 4 templates cover most use-cases:

| Template | When to use | How to customise |
|---|---|---|
| **1. Quote drop** | After posting a reel or carousel — pull a line from it, share in stories as "you missed this" | Swap headline. Change tag to reference the post it's from |
| **2. BTS / Founder log** | Weekly — show something raw about building. Dark bg, green accent | Swap the "Day 47" line to the real day count. Add photo if relevant |
| **3. Waitlist teaser** | Once every 2 weeks — direct waitlist push | Update the headline (e.g. "first 1000" vs "first 500") |
| **4. Poll / ask** | Weekly — use IG's native poll sticker on top of this template | IG adds the sticker on top; use template as a visual frame |

**Posting stories:** export each as PNG at 2x from Figma, then upload to IG stories. Layer IG's native stickers (polls, questions, links) on top in IG's story editor.

## Production workflow at a glance

**Setup (one-time, ~30 min):**
- [ ] Export all 22 carousel PNGs from Figma to a folder on your desktop
- [ ] Export the 4 story templates
- [ ] Install CapCut (free) if you haven't
- [ ] Install Ideogram and test one postcard generation

**Weekly rhythm (~3 hours per week):**
- [ ] **Sunday evening — plan:** open CONTENT-CALENDAR.md, confirm the week's 4 posts
- [ ] **Monday morning — post #1:** upload, caption, hashtags (10 min)
- [ ] **Wednesday — post #2:** same
- [ ] **Friday — post #3:** same
- [ ] **Saturday — shoot reels:** if next week has reels, batch-shoot the b-roll in one session
- [ ] **Sunday — post #4:** same as Monday

**Monthly (~4 hours):**
- [ ] Review saves/shares per post. Kill formats that underperform, double down on winners.
- [ ] Generate next batch of postcards in Ideogram (1 hour)
- [ ] Edit next batch of reels in CapCut (2–3 hours)

## Realistic expectations from zero

From 0 followers, the first 15–20 posts will underperform while you're priming the algorithm. The breakout usually comes between post 15 and post 50 — typically a reel, typically not the one you expected. Don't optimise for that post; optimise for the 50 that come before it.

**Signals you're on track (weeks 1–4):**
- Save rate > 3% on at least 1 post per week
- Share-to-reach > 0.5% on at least 1 post per week
- Profile visits / post ≥ 20
- Waitlist signups measurable (add `?src=ig` to your link)

**Signals you're not on track:**
- Save rate < 0.5% across every post in a week → hooks aren't landing, revisit the first 2 seconds
- Zero comments → you're not engaging first 2 hours, or the content isn't conversation-starting
- Followers grow but waitlist doesn't → caption CTAs aren't clear enough, or bio isn't converting

If the second column happens 3 weeks in a row, we adjust.
